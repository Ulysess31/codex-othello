오델로 작성을 위한 기술 스펙을 AGENTS.md 파일에 작성해줘.
HTML, CSS, JavaScript, React 등을 이용하고, 유지보수하기 좋고 최적화된 심플한 구조로 개발 규칙을 정해줘.
초보 개발자가 이해하기 쉬워야 해.

memory-bank 아래 design-document.md 파일을 참고해서 구체적인 계획을 implement.md로 작성해줘.
